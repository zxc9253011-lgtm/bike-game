# 森森騎旅 — 點開就能玩

## [點這裡直接開始遊戲](https://zxc9253011-lgtm.github.io/bike-game/)

**網站已上線，不需要下載、解壓縮或安裝。**

1. 點上方「直接開始遊戲」。
2. 進入後按「開始騎行」即可試玩。
3. 要用實際踩踏控制，切換「使用攝影機」並允許權限，讓鏡頭拍到肩膀、髖部、膝蓋和腳踝。

坐穩後像空中腳踏車一樣交替抬腿，踩得越快，角色騎得越快。影像只在裝置中分析，不錄影、不上傳。

提供森林、海岸、夕陽 3D 場景、騎車角色、動作標點、示範模式、暫停、時間與虛擬里程紀錄，以及友善大字模式。
