# 森森騎旅 — 直接在瀏覽器玩

網站啟用後，直接點 **[開始遊戲](https://zxc9253011-lgtm.github.io/bike-game/)**，不需要下載或安裝。

## 程式庫擁有者首次開啟網站

1. 開啟 [Settings → Pages](https://github.com/zxc9253011-lgtm/bike-game/settings/pages)。
2. Source 選 **Deploy from a branch**。
3. Branch 選 **gh-pages**，資料夾選 **/ (root)**，按 **Save**。
4. 等 GitHub 發布完成後，即可開啟上方遊戲網址。之後不需要重複設定。

網頁檔案已上傳到 `gh-pages`，完整原始碼在 [main 分支](https://github.com/zxc9253011-lgtm/bike-game/tree/main)。

## 遊玩

先按「開始騎行」試玩。要實際踩踏控制速度，選「使用攝影機」並允許權限，讓鏡頭完整拍到肩膀、髖部、膝蓋和腳踝，坐穩後交替抬腿。影像只在裝置中分析，不錄影、不上傳。

提供森林、海岸、夕陽 3D 場景、騎車角色、姿態標點、踩踏速度控制、暫停、時間與里程紀錄，以及友善大字模式。
