# 森森騎旅 — Windows 免安裝版

坐著踩空中腳踏車，騎進 3D 自然風景。適用 Windows 10／11 64 位元。

## 下載與開啟

1. [下載 Windows 遊戲壓縮檔（約 44 MB）](https://github.com/zxc9253011-lgtm/bike-game/raw/refs/heads/downloads/forest-pedal-windows.zip)。如果是私人程式庫，請先登入有權限的 GitHub 帳號。
2. 下載完成後，按右鍵 →「全部解壓縮」。
3. 打開解壓縮後的 `ForestPedal` 資料夾，點兩下 `start-windows.cmd`。
4. 遊戲會自動在瀏覽器開啟。黑色啟動視窗需保持開啟，結束遊戲時再關閉。
5. 先按「開始騎行」試玩。實際踩踏時選「使用攝影機」並允許權限，讓鏡頭完整拍到肩膀、髖部、膝蓋和腳踝。

已包含經官方 SHA256 校驗的 Node.js 執行程式，無須另外安裝 Node.js 或輸入指令。攝影機影像僅在本機分析，不錄影、不上傳。請勿直接開啟 `app/index.html`。

## 內容

- 森林、海岸與夕陽 3D 場景，以及騎車角色動畫。
- 攝影機姿態標點、踩踏速度控制及示範模式。
- 暫停、騎行時間、虛擬里程紀錄與友善大字模式。

這個 `downloads` 分支只保存可下載的電腦版，不包含開發檢出目錄的變動。
