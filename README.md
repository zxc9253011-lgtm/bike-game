# 森森騎旅

坐著踩空中腳踏車，或原地輕鬆踏步，都能走進 3D 風景。以 React、TypeScript、Three.js 與本機 MediaPipe Pose 製作，介面為繁體中文。

## 直接在瀏覽器玩

**[點這裡直接開始遊戲](https://zxc9253011-lgtm.github.io/bike-game/)**。網站已部署到 GitHub Pages，無須下載、安裝或輸入指令。使用攝影機時，請允許瀏覽器權限。

`main` 保存原始碼，`gh-pages` 保存編譯後的靜態網站，`downloads` 保存先前的 Windows 下載版。更新網頁版可執行 `npm run publish:pages`；此指令會建置並推送網站至 GitHub，請只在已取得發布授權時執行。

GitHub Pages 建置使用 `/bike-game/` 子路徑，圖片與本機姿態辨識資產會一起依此路徑載入；一般開發與 Windows 版仍使用根路徑。

## Windows 下載版

開發者執行 `npm run package:desktop` 可產生 `exports/forest-pedal.zip`。完整解壓縮後，使用者點兩下 `ForestPedal/start-windows.cmd` 即可自動開啟遊戲。Windows 10/11 64 位元版已包含經官方 SHA256 校驗的 Node.js 執行程式，不需自行安裝 Node.js 或輸入指令。黑色啟動視窗需保持開啟，結束遊戲時再關閉。請勿直接開啟 `app/index.html`。

打包需要 Node.js、Python 3 與 curl。首次打包會由官方 nodejs.org 下載固定版本的 Windows 執行程式；來源、校驗及授權保存在壓縮檔的 `runtime/` 內。若要重建 Windows 執行程式快取，執行 `npm run assets:windows`。Mac/Linux 的附贈啟動檔仍需要電腦先安裝 Node.js。

## 開始使用

需要 Node.js 22.18 以上及支援 WebGL 的現代瀏覽器。

```sh
npm ci --cache /tmp/bike-game-npm-cache
npm run dev
```

1. 選擇「坐姿踩踏」、「站姿高抬膝」或新增的「原地踏步跑步」，再選「單人漫遊」或「雙人競賽」。雙人為同一台裝置、同一個鏡頭的同場競賽。
2. 選擇森林、海岸或暖陽山丘。雙人可設定 50／100／250／500 公尺賽程。
3. 可以先用「先試玩看看」，開始後拖動速度滑桿；雙人有兩個獨立滑桿與 3 秒同步倒數。
4. 真正運動時，選「使用攝影機」並允許權限。高抬膝與跑步需拍到肩部、髖部與膝蓋，坐姿還需拍到腳踝；雙人依鏡像畫面分為左側綠色玩家 1、右側藍色玩家 2。雙方辨識完成才能開賽。
5. 坐姿像踩空中腳踏車般左右交替；站姿需膝蓋抬到髖部高度附近，再放下並換腳，才算有效高抬膝。小幅踏步、一直抬著同一隻腳及同時抬雙膝不會持續計分。
6. 「原地踏步跑步」只要以舒服的幅度左右交替小步踏動，沒有膝蓋抬至髖部或特定高度的要求；3D 長者會步行／跑步，踏步越快，前進越快。影像抖動、站著不動或雙腿一起晃動不計步，停下會歸零。此模式同樣支援單人、雙人、全螢幕和運動紀錄。
7. 人體偵測固定在遊戲右上角，進入全螢幕仍使用同一個影像串流與模型，可收合／展開。全螢幕內也能在暫停時切換運動與玩法。
8. 雙人採加寬六道跑道：中央雙實線分開兩位玩家，每人的三條跑道以白色虛線分隔。鏡頭朝正中、減少周圍景物，集中顯示跑道與物件；切回單人恢復原風景。雙人各自控制自己的 3D 單車或跑步角色，第一位抵達終點者獲勝；若同時抵達則為平手。兩人的成績取自同一個完賽時刻，結果與運動模式會保存在目前瀏覽器。
9. 跑步模式預設開啟「收金幣・避炸彈」專注小遊戲，可在暫停時關閉。人留在原地踏步，角色以左／中／右三道收指定星星或葉子幣、避開炸彈；先放下雙手，再抬單手略高於肩可換一道，也可用畫面按鈕、玩家 1 的 ←／↓／→ 或 A／S／D、玩家 2 的 J／K／L。每次新旅程隨機排列，預覽與實際碰撞共用同一 seed。一般選擇排之間相距 18 公尺，另有每 4 公尺一枚、同道四枚的連續金幣串；金幣串的其他空白道不加分，沒有炸彈的排不計避彈獎分。每四排更換目標，練習觀察、記住規則與選擇；停下踏步或暫停時物件不再接近。碰到炸彈給溫和提醒，不倒扣分數、不停止跑步，也不改變里程競賽。結束後儲存各自收對金幣、避彈、碰彈、非目標金幣、遊戲分數與選對率；這些數據只代表本次遊戲表現。
10. 單人按「結束旅程」儲存；雙人抵達終點自動儲存。設定內可開啟友善大字模式與輕柔環境音。變更暫停中的運動／玩法會保存上一段並開始新旅程。

攝影機需要 **HTTPS 或 localhost**。遠端測試請使用 HTTPS；單純以區網 HTTP 開啟，瀏覽器通常不會提供攝影機權限。請在有足夠活動空間、穩固且有靠背的椅子上使用，並以個人舒適程度為準。

取景時需讓髖部與膝蓋完整入鏡；只拍到臉會顯示後退／調整鏡頭的提示，不會當成有效踏步。雙人各站在鏡像畫面的左右區域。

## 建置與驗證

```sh
npm run build
npm test
# 先在另一個終端執行 npm run dev
npm run test:browser
npm run test:multiplayer
npm run test:standing-motion
npm run test:tracking
npm run test:running
npm run test:cognitive
npm run test:dual-track
```

瀏覽器測試預設使用 `/usr/bin/chromium`；其他位置可設定 `CHROMIUM_PATH`，測試目標可設定 `BASE_URL`。測試涵蓋開始、速度變化、暫停、路線切換、儲存紀錄、攝影機拒絕權限、全螢幕人體視窗、雙人倒數與獨立速度、雙方勝負及手機版面。86 項單元測試涵蓋踩踏、完整交替高抬膝、輕幅踏步、雜訊、停止／重設與公平完賽。

```sh
# 選用：實際本機模型與攝影機流程整合測試
# 需要 Git、ffmpeg、Chromium，並會下載官方測試圖片至 /tmp。
npm run test:pose
npm run test:dual-pose
# 跑步模式正式模型靜止驗證（確認不會憑抖動計步）
EXERCISE_MODE=running npm run test:pose
```

`test:standing-motion` 使用明確標示的攝影機／Pose 測試替身，將每步約 3 秒、2 fps 且抬膝時腳踝遮擋的動態座標送進正式分析流程，驗證單／雙人車速、距離、停止及小幅踏步拒絕。此測試不是實際運動影片的模型驗證；真模型載入與標點流程由上述整合測試覆蓋。

站姿完成第一個完整抬高／放下動作即提供保守的速度估計，後續以左右交替步間隔計速；支援每步 2–5 秒的慢速運動，停下時依最近步速歸零。

`test:tracking` 使用明確標示的測試替身，讓推論實際等待 1.9 秒或永久不回應，驗證雙人骨架持續顯示、慢速動作前進、一次自動重建保留攝影機，以及再次失敗後可手動重新連線。

`test:running` 使用明確標示的攝影機／Pose 替身，將膝蓋遠低於髖部、僅約 0.07 軀幹長度的微小交替動作送入正式分析，驗證單雙人速度、獨立步數、停止、同步晃動拒絕、全螢幕攝影機、手機版面與跑步紀錄；不冒稱真實運動影片的模型驗證。

`test:cognitive` 用實際示範跑步的時間與距離跨越物件，驗證金幣／炸彈／非目標幣判定、目標切換、暫停、獨立雙人成績、儲存及重新載入。只有手勢場景使用明確標示的攝影機／Pose 替身；不注入 App 遊戲分數或路程。

`test:dual-track` 實際跑過六道寬路、中央／虛線標記、連續四枚金幣、獨立雙人、重設隨機種子、桌面與手機畫面。反應時間場景使用明確標示的攝影機／Pose 替身；其輸出是 App 排程與計算時間，不能代表所有真實攝影機或電腦的總延遲。

## 動作分析與隱私

- 模型使用官方 `@mediapipe/pose@0.5.1675469404` 的 Lite 模式，資產隨專案保存在 `public/pose/`，不依賴執行時 CDN。
- 動作處理縮小輸入影像、縮短推論排程間隔，雙人交替優先處理；抬手穩定判定為 180ms，踏步平滑時間常數為 45ms。雙人降低場景像素比和陰影負擔；完整入鏡、光線與硬體仍會影響實際辨識速度。
- 每位玩家完成分析即更新骨架與數值，辨識較慢時自動調整追蹤時限；分析卡住會嘗試一次重建模型並保留原攝影機，仍失敗時顯示重新連線。
- 攝影機只有在使用者選取攝影機模式後才啟動；切回示範模式即停止影像串流並釋放模型。
- 即時影像與關節座標只在瀏覽器處理，不錄影、不上傳、不存入運動紀錄。
- 雙人使用同一影像左右分區與兩個獨立模型，不會用一個人的運動替代另一個人；缺席或低辨識信心的玩家速度為零。
- 依腿部與軀幹的相對位置估計左右交替運動，用遲滯、平滑與週期中位數計算完整踩踏 rpm。靜止雜訊、關節不在畫面內或低辨識信心時不會推動角色。
- 里程為遊戲模擬值，騎行速度對應為 `rpm × 0.28 km/h`；跑步以兩步作一個等效週期，遊戲速度為 `等效週期/分 × 0.16 km/h`，上限 12 km/h，並非實際車速或醫療量測。攝影機角度、衣著、照明與遮擋會影響辨識，實際長者使用仍需在裝置上試踩並調整位置。

資產來源、版本與 SHA 校驗記錄於 `public/pose/provenance.json`，授權見 `public/pose/LICENSE`。需要重建模型資產時：

```sh
npm run assets:pose
```

此指令從官方 npm 來源取得固定版本，驗證完整 SHA512 後再解壓縮，保留正常 TLS 驗證。3D 世界、騎行角色與路線縮圖皆由專案程式與 SVG 產生。

## 專案結構

- `src/App.tsx`：遊戲狀態、速度、計時、目標與本機紀錄。
- `src/components/RideScene.tsx`：3D 世界、角色動畫與不同路線。
- `src/components/PoseCamera.tsx`：攝影機、標點疊圖、模型生命週期與示範動畫。
- `src/lib/cadence.ts`：可獨立測試的踩踏頻率計算。
- `src/lib/marching.ts`：無絕對高度要求的左右輕踏步、雜訊排除、慢速支援及有效步數。
- `src/lib/exercise.ts`：三種模式名稱與遊戲速度換算。
- `src/lib/highKnee.ts`：帶抬高／放下門檻、左右交替與停止判定的有效高抬膝計數。
- `src/lib/cognitiveRun.ts`：可測試的三道金幣／炸彈與目標切換、分數及遊戲摘要。
- `src/lib/steering.ts`：抬手穩定時間、回復中立、冷卻與低信心拒絕。
- `src/components/CognitiveRun.tsx`：認知小遊戲設定、目標、選道與成果。
- `src/lib/race.ts`：獨立雙人距離、精確抵達時刻、平手與完賽凍結。

雲端任務請直接使用既有 `/workspace/bike-game` 檢出目錄，無需建立額外 Git worktree。
